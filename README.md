# Meine Lern-App

Lern-App für die Mittelschule (1. und 2. Klasse): Mathe, Deutsch, Englisch, Biologie, Geografie, Geschichte, Physik, Musik, Sprachen, Bibliothek und mehr.

Alle Lernfortschritte werden nur im Browser des jeweiligen Geräts gespeichert – nicht hier im Repository.

Bildnachweise: Fotos und Wappen von Wikimedia Commons (siehe „Bildnachweise“ in der App), Flaggen: flag-icons (MIT), Kartendaten: Natural Earth, Städte: GeoNames (CC BY 4.0).

## Lern-App 4. Klasse Volksschule (`vs4/`)
Eigene App unter `/vs4/` mit Profilen, Rechen-Werkstatt (kleinschrittig, mit Bildern, ohne Zeitdruck, passt sich an), Mathematik, Deutsch, Sachunterricht und Englisch. Nutzt denselben KI-Server (`../config.js`, `../ki.js`). Alle Lerndaten bleiben nur auf dem Gerät.
